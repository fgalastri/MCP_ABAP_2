# Getting Started with Documentation

Welcome to the centralized documentation system!

## How to Use

This documentation system provides access to all development standards, guidelines, and best practices through the MCP (Model Context Protocol) server.

### Available Commands

1. **List all documentation**: Use `list_docs` tool
2. **Search documentation**: Use `search_docs` with keywords
3. **Get specific document**: Use `get_doc` with document ID
4. **Browse categories**: Use `get_categories` to see available categories

### Categories

- **standards**: Coding standards and conventions
- **guidelines**: Development guidelines and best practices
- **best-practices**: Recommended approaches and patterns
- **general**: General documentation and FAQs

### Document IDs

Document IDs are based on the filename (without .md extension). For example:
- File: `coding-standards.md` → ID: `coding_standards`
- File: `rap-best-practices.md` → ID: `rap_best_practices`

## Tips

- Use search to find relevant documentation quickly
- Check categories to browse related documents
- Documents include metadata (tags, descriptions) for better discovery
